# Smart home

- `web/` - the 3D house web app (Three.js + Supabase). Published with GitHub Pages.
- `firmware/` - ESP32 relay board code (PlatformIO).
- `supabase/` - database tables and rules (schema `smarthome`).
- `CLAUDE.md` - the full plan and safety rules.

Edit room sizes, furniture and lights in `web/house.js`.
